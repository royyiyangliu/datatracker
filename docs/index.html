口径说明

  • 采用率：当月在 Ramp 上有 AI 产品或服务正向付费交易（企业卡、账单、ACH）的企业占比；免费工具和员工个人账户不计入，可能低估实际使用。
  • 人均月 AI 支出：当月 AI 支出 ÷ 员工数，只统计有 AI 支出的企业。
  • AI 占企业支出比例：分母为经 Ramp 支付的全部支出（企业卡、账单 / ACH），工资通常不经 Ramp 发放，因此不在其中；分子包括大模型订阅、编程助手订阅、API token 以及 GPU 云和基础设施支出。行业按 NAICS 分类，不含未识别行业。
  • Token 支出 / 用量：来自接入 Ramp Token Spend Management 的企业，从各 AI 提供商账单按模型归属；不代表 Ramp 全体客户，少数大客户可能显著影响份额。
  • Token 价格：Ramp 单独发布的价格序列，样本与 token 支出图不完全相同，两者数值不宜直接换算。
  • 样本企业数随时间增长（2023 年中约 1.3 万家，2026 年约 6.5 万家），早期与近期的企业构成不同。
